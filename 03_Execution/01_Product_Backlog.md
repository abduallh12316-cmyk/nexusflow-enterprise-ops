# Product Backlog

Create GitHub Issues from `../data/tasks.csv` and `../data/defects.csv`.

Suggested epics:
- EPIC-01 Identity and Access Management
- EPIC-02 Requests and Approval Workflows
- EPIC-03 Project and Task Tracking
- EPIC-04 KPI Dashboard and Reporting
- EPIC-05 Auditability and Compliance
- EPIC-06 DevOps, Security and Release
- EPIC-07 Training and Operational Handover

Each issue should include ID, objective, fictional owner, priority, due date, dependencies, acceptance criteria, and evidence of completion. Do not create GitHub assignees unless the real GitHub users are known.
