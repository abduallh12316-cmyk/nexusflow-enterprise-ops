# Communications Plan

| Communication | Audience | Frequency | Owner | Channel | Purpose |
|---|---|---|---|---|---|
| Weekly status report | Sponsor, Product Owner, workstream leads | Weekly | Project Manager | Draft email + report | Progress, variance, decisions |
| Delivery review | Core team | Weekly | Project Coordinator | Meeting | Actions, blockers, dependencies |
| Risk review | PM, owners, Security, QA | Weekly | Project Manager | Meeting/register | Mitigation and escalation |
| Steering update | Sponsor and leaders | Monthly / by exception | Project Manager | Executive report | Decisions and baseline changes |
| Change decision | Sponsor, requester, PM | Per request | Project Manager | Decision log + email draft | Approve/reject/defer change |
| Go-live readiness | Sponsor, Engineering, QA, Operations | Before release gate | Project Manager | Readiness review | Release authorization |

All outbound email actions remain draft-only unless a human explicitly approves live sending.
